# Install and get started

[User guide](index.md)

## Install on the TV

Milkbeat requires Android TV, Google TV or Fire TV running Android 8.0 or later.

1. Download an APK from the [latest release](https://github.com/johnneerdael/Milkbeat/releases/latest).
2. Use `milkbeat-universal.apk` if you are unsure about your device's architecture. ARM64 and ARMv7 APKs are also available.
3. Open the APK with the TV's installer. Enable installation from that source if Android asks.
4. Start Milkbeat from the launcher.

The Downloader app accepts code **7170062** for the release download. Subsequent Milkbeat release APKs can be installed over the existing app to preserve its data and sign-ins. Uninstalling first removes app data.

## First playback

For your own files, [add a local folder or an SMB, WebDAV, SFTP or NFS server](folders.md). No plugin is needed.

For a streaming catalog, [install providers and sign in](providers.md). Each one you can use gets its own tab in the sidebar. Until a provider or folder offers music, a single **Music** tab offers to add a plugin or a music folder; Library → Folders still plays your folders.

## Remote controls

| Control | Action |
| --- | --- |
| Direction buttons | Move focus through the interface |
| OK / center | Open the focused item or activate its action |
| Back | Close a pane or return to its parent |
| Hold Up or Down in the queue | Scroll repeatedly, accelerating through a long queue |
| Left / Right with player controls hidden | Previous / random visualizer preset |
| OK in the full music player | Show playback controls |

The left menu opens Music, Search, Library and Settings. Settings has a category list on the left and its controls on the right.
